 # Student Record Management System
 ## Phase 1: Menu Structure, Functions, Arrays and Data Management 
 A C programming project designed to manage student records in memory using parallel arrays and modular function structure.


 ### Project Overview
 This system provides an interactive main menu that allows users to store, manage, and process student records (up to 100 students) dynamically during program execution.

 ### Student Record Structure:
 Each student record contains:
 * **Student ID:** A unique 4-digit integer.
 * **Name:** A non-empty string (up to 49 characters).
 * **Age:** positive integer ranging from 6 to 50.
 * **GPA:** Double floating-point value between 0.0 and 4.0 inclusive.



### Key Features & Learning Objectives:
* **Modular Programming:** Clean code structure divided into functions ('addStudent()', display, search, etc.).
* **Data Storage:** Uses Parallel Arrays as an in-memory data storage method.
* **Array Operations:** Display all records, linear search, insert, and delete student data.
* **Robust Input Validation:** Rejects duplicate IDs, out-of-range ages/GPAs, and invalid inputs before accepting data.
* **Interactive Menu:** Menu driven structure using loops for continuous user choices.
